About This Project

The Smart Student Tracking System is a final-year engineering project that brings together face-recognition attendance, live GPS bus tracking, and automated parent notifications on a single platform for admins, bus drivers, and parents.

Built with
  • Flask + MySQL for the backend and data layer
  • OpenCV (LBPH) for face-recognition attendance
  • ESP32 + NEO-6M GPS module for live location tracking
  • Leaflet for map rendering, Bootstrap 5 for the interface
